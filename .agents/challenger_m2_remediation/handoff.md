## 2. Logic Chain

1. **Bottom-Up Bounds Calculation (`get_subgraph_bounds` in `mermaid_converter.py`)**:
   - Leaf nodes contribute points: `(nx, ny)` to `(nx + 140, ny + 60)`.
   - Child subgraphs recursively evaluate bounds `(cx, cy, cw, ch)` and contribute points `(cx, cy)` to `(cx + cw, cy + ch)`.
   - Content bounding box for any subgraph `S` is calculated as `content_x_min`, `content_y_min`, `content_x_max`, `content_y_max`.
2. **Container Padding & Swimlane Header Offset**:
   - Subgraph cell coordinates are computed as:
     - `sub_x = content_x_min - 20`
     - `sub_y = content_y_min - 35`
     - `sub_w = (content_x_max - content_x_min) + 40`
     - `sub_h = (content_y_max - content_y_min) + 45`
   - Swimlane style specifies `startSize=25` (25px header height).
   - Header bar of parent subgraph spans `[sub_y, sub_y + 25]`.
   - Content top `content_y_min` is at `sub_y + 35`, leaving `35 - 25 = 10px` clear visual vertical margin between the header bar bottom and child elements.
3. **Inductive Preservation Across Nesting Levels**:
   - For level $N$ parent enclosing level $N-1$ child:
     - $X_{parent} = X_{child} - 20$
     - $Y_{parent} = Y_{child} - 35$
     - $Right_{parent} = Right_{child} + 20$
     - $Bottom_{parent} = Bottom_{child} + 10$
   - This exact delta holds for 1-level, 2-level, and 3-level subgraphs.
4. **Ordering of Builder Output**:
   - `mermaid_converter.py` sorts subgraphs by depth (top-down, outer parents first: line 333) when adding swimlane cells to `builder`, ensuring proper parent-child z-indexing and layout hierarchy in Draw.io.
